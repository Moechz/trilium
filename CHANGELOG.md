# Changelog

All notable user-visible changes to the Trilium TOS application package.

## 0.103.0-1 — 2026-11-10

### Added
- First release. Trilium (`triliumnext/trilium:v0.103.0`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8044 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/triliumdocker/`.
